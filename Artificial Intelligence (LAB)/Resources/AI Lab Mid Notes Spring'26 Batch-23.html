Q1 TOPIC Uninformed Search — BFS, DFS, UCS

🔵 Breadth-First Search (BFS)

Explores all nodes at the current depth before going deeper. Uses a queue (FIFO). Guaranteed to find the shortest path (in terms of number of steps, not cost).

Key Properties

  • Complete: Yes — will always find a solution if one exists
  • Optimal: Yes — for uniform-cost edges (finds fewest hops)
  • Data structure: Queue (FIFO)
  • Time/Space: O(b^d) where b = branching factor, d = depth

Algorithm Steps

  1. Put the start node in the queue; mark it visited.
  2. Dequeue the front node. If it's the goal, reconstruct path and stop.
  3. For each unvisited neighbor, enqueue it and mark visited.
  4. Repeat until queue is empty (no solution) or goal found.
Python — BFS on a 2D Grid
from collections import deque

def bfs(grid, start, goal):
    rows, cols = len(grid), len(grid[0])
    queue = deque([(start, [start])])   # (current_pos, path_so_far)
    visited = {start}

    while queue:
        (r, c), path = queue.popleft()
        if (r, c) == goal:
            return path            # Found!
        for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:   # Up Down Left Right
            nr, nc = r+dr, c+dc
            if 0 <= nr < rows and 0 <= nc < cols \
               and (nr, nc) not in visited \
               and grid[nr][nc] != '#':
                visited.add((nr, nc))
                queue.append(((nr, nc), path + [(nr, nc)]))
    return None   # No path found

# BFS on a graph (adjacency list)
def bfs_graph(graph, start, goal):
    queue = deque([(start, [start])])
    visited = {start}
    while queue:
        node, path = queue.popleft()
        if node == goal: return path
        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return None

🔵 Depth-First Search (DFS)

Explores as deep as possible along each branch before backtracking. Uses a stack (LIFO) or recursion. Not guaranteed to find the shortest path.

Key Properties

  • Complete: No — can get stuck in infinite loops (use visited set)
  • Optimal: No — may find a longer path first
  • Data structure: Stack (LIFO)
  • Space: O(b·m) — better than BFS for deep solutions
Python — DFS on a 2D Grid
def dfs(grid, start, goal):
    rows, cols = len(grid), len(grid[0])
    stack = [(start, [start])]
    visited = {start}

    while stack:
        (r, c), path = stack.pop()   # LIFO — use stack.pop()
        if (r, c) == goal:
            return path
        for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
            nr, nc = r+dr, c+dc
            if 0 <= nr < rows and 0 <= nc < cols \
               and (nr, nc) not in visited \
               and grid[nr][nc] != '#':
                visited.add((nr, nc))
                stack.append(((nr, nc), path + [(nr, nc)]))
    return None

🔵 Uniform Cost Search (UCS)

Like BFS but uses a priority queue (min-heap) ordered by cumulative path cost. Finds the truly optimal (lowest-cost) path even when edge costs differ.

Key Properties

  • Complete: Yes (if costs > 0)
  • Optimal: Yes — always finds minimum-cost path
  • Data structure: Priority queue (heapq)
Python — UCS on a Cost Grid
import heapq

def ucs(grid, start, goal):
    # grid[r][c] = cost to enter that cell (int), '#' = obstacle
    rows, cols = len(grid), len(grid[0])
    # heap: (total_cost, current_pos, path)
    heap = [(0, start, [start])]
    visited = {}   # pos -> best cost seen

    while heap:
        cost, (r, c), path = heapq.heappop(heap)
        if (r, c) == goal:
            return path, cost
        if (r, c) in visited and visited[(r,c)] <= cost:
            continue
        visited[(r, c)] = cost
        for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
            nr, nc = r+dr, c+dc
            if 0 <= nr < rows and 0 <= nc < cols \
               and grid[nr][nc] != '#':
                new_cost = cost + int(grid[nr][nc])
                heapq.heappush(heap, (new_cost, (nr, nc), path+[(nr,nc)]))
    return None, float('inf')
📌 Tip: BFS = queue, DFS = stack, UCS = min-heap. The only difference between BFS and UCS in code is the data structure used.

Q2 TOPIC Informed Search — Greedy Best-First & A*

🟠 Greedy Best-First Search (GBFS)

Uses a heuristic h(n) to always expand the node that appears closest to the goal. Fast but not optimal — it ignores the cost already paid.

Formula

Priority = h(n) only

Key Properties

  • Complete: No (can get trapped in loops)
  • Optimal: No
  • Speed: Very fast when heuristic is good
Python — GBFS on a 2D Grid
import heapq

def manhattan(a, b):
    return abs(a[0]-b[0]) + abs(a[1]-b[1])

def gbfs(grid, heuristic, start, goal):
    # heuristic[r][c] = h value given in the problem
    rows, cols = len(grid), len(grid[0])
    heap = [(heuristic[start[0]][start[1]], start, [start])]
    visited = set()

    while heap:
        h, (r, c), path = heapq.heappop(heap)
        if (r, c) == goal: return path
        if (r, c) in visited: continue
        visited.add((r, c))
        for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
            nr, nc = r+dr, c+dc
            if 0 <= nr < rows and 0 <= nc < cols \
               and (nr,nc) not in visited \
               and grid[nr][nc] != '#':
                heapq.heappush(heap,
                    (heuristic[nr][nc], (nr,nc), path+[(nr,nc)]))
    return None

🟠 A* Search

Combines actual cost so far g(n) and heuristic estimate h(n). Optimal and complete when the heuristic is admissible (never overestimates).

Formula

Priority = f(n) = g(n) + h(n)

  • g(n) = actual cost from start to n
  • h(n) = heuristic estimate from n to goal

Common Heuristics

  • Manhattan distance (grid, no diagonal): |Δrow| + |Δcol|
  • Euclidean distance (any direction): √(Δrow² + Δcol²)
Python — A* on a 2D Grid
import heapq

def astar(grid, start, goal, cost_grid=None):
    """
    grid[r][c]: '#' = wall, else passable
    cost_grid[r][c]: cost to enter cell (default 1 if None)
    """
    rows, cols = len(grid), len(grid[0])
    def h(r, c):   # Manhattan heuristic
        return abs(r - goal[0]) + abs(c - goal[1])
    def step_cost(r, c):
        if cost_grid: return cost_grid[r][c]
        return 1

    # heap: (f, g, pos, path)
    heap = [(h(*start), 0, start, [start])]
    best_g = {}   # pos -> best g seen

    while heap:
        f, g, (r, c), path = heapq.heappop(heap)
        if (r, c) == goal: return path, g
        if best_g.get((r,c), float('inf')) <= g: continue
        best_g[(r, c)] = g
        for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
            nr, nc = r+dr, c+dc
            if 0 <= nr < rows and 0 <= nc < cols \
               and grid[nr][nc] != '#':
                ng = g + step_cost(nr, nc)
                nf = ng + h(nr, nc)
                heapq.heappush(heap, (nf, ng, (nr,nc), path+[(nr,nc)]))
    return None, float('inf')
📌 Key Insight: A* with h=0 becomes UCS. A* with g=0 becomes GBFS. A* is the sweet spot between the two.

Q3 TOPIC Genetic Algorithms — Complete Reference

🟢 GA Overview & Lifecycle

Genetic Algorithms mimic natural selection to optimize solutions. Each individual (chromosome) represents a candidate solution.

  1. Initialize Population — Create random individuals.
  2. Evaluate Fitness — Score each individual.
  3. Selection — Choose parents based on fitness.
  4. Crossover — Combine parent genes to make offspring.
  5. Mutation — Randomly alter some genes.
  6. Replacement — Form next generation.
  7. Repeat until termination condition met.

🟢 Selection Methods

1. Tournament Selection ⭐ (Exam Focus)

Pick k random individuals; the best one is the winner (parent). Repeat for second parent.

import random

def tournament_selection(population, fitnesses, k=3):
    """Select one parent via tournament of size k."""
    tournament = random.sample(list(zip(population, fitnesses)), k)
    winner = max(tournament, key=lambda x: x[1])
    return winner[0]   # return the individual

2. Roulette Wheel (Fitness-Proportionate) Selection

Each individual's probability of selection = fitness / total_fitness. Spin the wheel.

def roulette_selection(population, fitnesses):
    total = sum(fitnesses)
    pick = random.uniform(0, total)
    current = 0
    for ind, fit in zip(population, fitnesses):
        current += fit
        if current >= pick:
            return ind

3. Rank-Based Selection

Sort by fitness; assign selection probability based on rank, not raw fitness value.

def rank_selection(population, fitnesses):
    ranked = sorted(zip(population, fitnesses), key=lambda x: x[1])
    ranks = [i+1 for i in range(len(ranked))]
    total = sum(ranks)
    pick = random.uniform(0, total)
    current = 0
    for (ind, _), rank in zip(ranked, ranks):
        current += rank
        if current >= pick: return ind

🟢 Crossover Techniques

1. Single-Point Crossover

Pick one random cut point; swap tails of both parents.

def single_point_crossover(p1, p2):
    pt = random.randint(1, len(p1)-1)
    child1 = p1[:pt] + p2[pt:]
    child2 = p2[:pt] + p1[pt:]
    return child1, child2

2. Two-Point Crossover ⭐ (Exam Focus)

Pick two cut points; swap the middle segment.

def two_point_crossover(p1, p2):
    size = len(p1)
    pt1, pt2 = sorted(random.sample(range(1, size), 2))
    child1 = p1[:pt1] + p2[pt1:pt2] + p1[pt2:]
    child2 = p2[:pt1] + p1[pt1:pt2] + p2[pt2:]
    return child1, child2

3. Uniform Crossover

For each gene, flip a coin — take from parent 1 or parent 2.

def uniform_crossover(p1, p2, prob=0.5):
    child1, child2 = [], []
    for g1, g2 in zip(p1, p2):
        if random.random() < prob:
            child1.append(g1); child2.append(g2)
        else:
            child1.append(g2); child2.append(g1)
    return child1, child2

4. Order Crossover (OX) ⭐ — For Permutation Problems (TSP)

Preserve relative order of genes. Used for Travelling Salesman Problem.

def order_crossover(p1, p2):
    size = len(p1)
    pt1, pt2 = sorted(random.sample(range(size), 2))
    child = [None] * size
    child[pt1:pt2] = p1[pt1:pt2]              # copy segment from p1
    remaining = [x for x in p2 if x not in child]
    idx = 0
    for i in range(size):
        if child[i] is None:
            child[i] = remaining[idx]; idx += 1
    return child

5. Partially Mapped Crossover (PMX)

Similar to OX but uses a mapping to resolve conflicts in permutations.

def pmx(p1, p2):
    size = len(p1)
    pt1, pt2 = sorted(random.sample(range(size), 2))
    child = [None] * size
    child[pt1:pt2] = p1[pt1:pt2]
    mapping = {p1[i]: p2[i] for i in range(pt1, pt2)}
    for i in range(size):
        if child[i] is None:
            val = p2[i]
            while val in mapping: val = mapping[val]
            child[i] = val
    return child

6. Cyclic Crossover (CX)

Preserves absolute positions of genes from parents via cycle detection.

def cyclic_crossover(p1, p2):
    size = len(p1)
    child = [None] * size
    idx, cycle = 0, 0
    while None in child:
        if child[idx] is not None: idx = child.index(None)
        start = idx
        while True:
            if cycle % 2 == 0: child[idx] = p1[idx]
            else: child[idx] = p2[idx]
            idx = p1.index(p2[idx])
            if idx == start: break
        cycle += 1
    return child

🟢 Mutation Techniques

1. Uniform Mutation ⭐ (Exam Focus)

Each gene independently has a chance to be replaced by a random value.

def uniform_mutation(individual, gene_pool, mutation_rate=0.1):
    return [random.choice(gene_pool) if random.random() < mutation_rate else g
            for g in individual]

2. Swap Mutation (for TSP/Permutation)

Pick two random positions and swap their genes.

def swap_mutation(individual):
    a, b = random.sample(range(len(individual)), 2)
    individual = individual[:]
    individual[a], individual[b] = individual[b], individual[a]
    return individual

3. Bit-Flip Mutation (Binary Chromosomes)

def bit_flip_mutation(individual, mutation_rate=0.05):
    return [1-g if random.random() < mutation_rate else g
            for g in individual]

🟢 Fitness Functions for Common Problems

TSP — Minimize Distance

import math

def tsp_distance(route, cities):
    """Total distance for a route (list of city indices)."""
    total = 0
    for i in range(len(route)):
        c1, c2 = cities[route[i]], cities[route[(i+1) % len(route)]]
        total += math.dist(c1, c2)
    return total

def tsp_fitness(route, cities):
    return 1 / tsp_distance(route, cities)   # higher is better

N-Queens — Minimize Conflicts

def nqueens_fitness(board):
    """board[i] = row of queen in column i"""
    n = len(board)
    conflicts = 0
    for i in range(n):
        for j in range(i+1, n):
            if board[i] == board[j] or abs(board[i]-board[j]) == j-i:
                conflicts += 1
    return -conflicts   # 0 conflicts = perfect solution

Complete GA Template (TSP)

import random, math

def distance(c1, c2): return math.dist(c1, c2)

def total_distance(route, cities):
    return sum(distance(cities[route[i]], cities[route[(i+1)%len(route)]])
                for i in range(len(route)))

def fitness(route, cities):
    return 1 / total_distance(route, cities)

def tournament_select(pop, fits, k=3):
    t = random.sample(list(zip(pop, fits)), k)
    return max(t, key=lambda x: x[1])[0]

def order_crossover(p1, p2):
    size = len(p1)
    a, b = sorted(random.sample(range(size), 2))
    child = [None]*size; child[a:b] = p1[a:b]
    rem = [x for x in p2 if x not in child]
    idx = 0
    for i in range(size):
        if child[i] is None: child[i]=rem[idx]; idx+=1
    return child

def mutate(route, rate=0.1):
    route = route[:]
    if random.random() < rate:
        a, b = random.sample(range(len(route)), 2)
        route[a], route[b] = route[b], route[a]
    return route

def genetic_algorithm(cities, pop_size=50, generations=500):
    n = len(cities)
    pop = [random.sample(range(n), n) for _ in range(pop_size)]

    for gen in range(generations):
        fits = [fitness(ind, cities) for ind in pop]
        best = pop[fits.index(max(fits))]

        new_pop = [best]   # Elitism: keep best
        while len(new_pop) < pop_size:
            p1 = tournament_select(pop, fits)
            p2 = tournament_select(pop, fits)
            child = order_crossover(p1, p2)
            child = mutate(child)
            new_pop.append(child)
        pop = new_pop

    fits = [fitness(ind, cities) for ind in pop]
    best = pop[fits.index(max(fits))]
    return best, total_distance(best, cities)

# Example usage:
cities = [(2,3), (5,7), (1,9), (8,2), (4,5)]
route, dist = genetic_algorithm(cities)
print(f"Best Route: {route}")
print(f"Total Distance: {dist:.2f} units")

from collections import deque

# Graph from the exam diagram (nodes A-M visible in image)
graph = {
    'W': ['A', 'C'],
    'A': ['W', 'B', 'D'],
    'B': ['A', 'E'],
    'C': ['W', 'F', 'D'],
    'D': ['A', 'C', 'G', 'F'],
    'E': ['B', 'H', 'G'],
    'F': ['C', 'D', 'G', 'I'],
    'G': ['D', 'E', 'F', 'J'],
    'H': ['E', 'K'],
    'I': ['F', 'L', 'J'],
    'J': ['G', 'I', 'K'],
    'K': ['H', 'J', 'M'],
    'L': ['I', 'M'],
    'M': ['K', 'L'],
    'N': []   # destination — connect based on actual graph
}

def bfs_path(graph, start, goal):
    queue = deque([(start, [start])])
    visited = {start}
    expanded = []

    while queue:
        node, path = queue.popleft()
        expanded.append(node)
        print(f"Expanding: {node} | Path so far: {' -> '.join(path)}")

        if node == goal:
            print(f"\n✅ GOAL FOUND!")
            print(f"Path: {' -> '.join(path)}")
            print(f"Expansion order: {expanded}")
            return path

        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return None

bfs_path(graph, 'W', 'N')

            print(f"Path: {path}")

Q3 — Genetic Algorithm for Vehicle Routing (14 pts)

Tasks: (1) Tournament Selection, (2) Two-Point Crossover, (3) Uniform Mutation, (4) Run and output best solution

import random, numpy as np

# ── Problem Setup ──────────────────────────────────────────
num_locations = 5
truck_capacity = 15
demands = [0, 4, 3, 5, 2]   # depot=0
distance_matrix = np.array([
    [0, 2, 9, 10, 4],
    [2, 0, 6, 4,  3],
    [9, 6, 0, 8,  7],
    [10,4, 8, 0,  5],
    [4, 3, 7, 5,  0]
])

# ── Chromosome: permutation of delivery points [1..n-1] ────
def random_individual():
    locs = list(range(1, num_locations))
    random.shuffle(locs)
    return locs

# ── Fitness: total distance (lower = better) ───────────────
def fitness(route):
    total_dist = 0
    load = 0
    prev = 0   # start at depot
    for loc in route:
        if load + demands[loc] > truck_capacity:
            total_dist += distance_matrix[prev][0]   # return to depot
            prev = 0; load = 0
        total_dist += distance_matrix[prev][loc]
        prev = loc; load += demands[loc]
    total_dist += distance_matrix[prev][0]   # return to depot
    return 1 / total_dist   # higher fitness = shorter route

# ── 1. Tournament Selection ────────────────────────────────
def tournament_selection(population, fitnesses, k=3):
    """Pick k random individuals; return the best one."""
    tournament = random.sample(list(zip(population, fitnesses)), k)
    winner = max(tournament, key=lambda x: x[1])
    return winner[0]

# ── 2. Two-Point Crossover ─────────────────────────────────
def two_point_crossover(parent1, parent2):
    size = len(parent1)
    pt1, pt2 = sorted(random.sample(range(1, size), 2))
    child1 = parent1[:pt1] + parent2[pt1:pt2] + parent1[pt2:]
    child2 = parent2[:pt1] + parent1[pt1:pt2] + parent2[pt2:]
    return child1, child2

# ── 3. Uniform Mutation ────────────────────────────────────
def uniform_mutation(individual, mutation_rate=0.2):
    """Each gene has equal probability of being randomly replaced."""
    mutated = individual[:]
    for i in range(len(mutated)):
        if random.random() < mutation_rate:
            mutated[i] = random.randint(1, num_locations-1)
    return mutated

# ── 4. Main GA Loop ────────────────────────────────────────
def run_ga(pop_size=20, generations=100):
    population = [random_individual() for _ in range(pop_size)]

    for gen in range(generations):
        fitnesses = [fitness(ind) for ind in population]
        best_idx = fitnesses.index(max(fitnesses))
        best_ind = population[best_idx]

        new_pop = [best_ind]   # elitism
        while len(new_pop) < pop_size:
            p1 = tournament_selection(population, fitnesses)
            p2 = tournament_selection(population, fitnesses)
            c1, c2 = two_point_crossover(p1, p2)
            new_pop.append(uniform_mutation(c1))
            if len(new_pop) < pop_size:
                new_pop.append(uniform_mutation(c2))
        population = new_pop

    fitnesses = [fitness(ind) for ind in population]
    best_idx = fitnesses.index(max(fitnesses))
    best = population[best_idx]
    best_dist = 1 / fitnesses[best_idx]
    print(f"Best Route: {best}")
    print(f"Total Distance: {best_dist:.2f}")
    return best, best_dist

run_ga()

Q1 — Medical Drone BFS with Utility Agent (14 pts)

Problem: Hospital graph of wards. Drone delivers medicine to critical patients using BFS. Utility = 10×critical_treated − moves.

from collections import deque

hospital = {
    "WardA": {"status": "Critical", "adjacent": ["WardB", "WardC"]},
    "WardB": {"status": "Normal",   "adjacent": ["WardA", "WardD"]},
    "WardC": {"status": "Critical", "adjacent": ["WardA", "WardD"]},
    "WardD": {"status": "Empty",    "adjacent": ["WardB", "WardC"]},
}

# ── Task 1: UtilityBasedAgent class ────────────────────────
class UtilityBasedAgent:
    def __init__(self, hospital, start):
        self.hospital = hospital
        self.current_ward = start
        self.moves = 0
        self.critical_treated = 0

    def utility(self):
        return 10 * self.critical_treated - self.moves

    # ── Task 2: BFS to nearest critical ward ───────────────
    def bfs_to_critical(self):
        queue = deque([(self.current_ward, [self.current_ward])])
        visited = {self.current_ward}
        while queue:
            ward, path = queue.popleft()
            if ward != self.current_ward and \
               self.hospital[ward]["status"] == "Critical":
                return path   # path[0]=current, path[-1]=target
            for neighbor in self.hospital[ward]["adjacent"]:
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append((neighbor, path+[neighbor]))
        return None

    # ── Task 3: Define agent actions ───────────────────────
    def act(self):
        ward_info = self.hospital[self.current_ward]
        if ward_info["status"] == "Critical":
            print(f"[{self.current_ward}] → DELIVER medicine 💊")
            self.hospital[self.current_ward]["status"] = "Treated"
            self.critical_treated += 1
        else:
            path = self.bfs_to_critical()
            if path and len(path) > 1:
                next_ward = path[1]
                print(f"[{self.current_ward}] → MOVE to {next_ward}")
                self.current_ward = next_ward
                self.moves += 1
            else:
                print("No critical patients remaining.")
                return False
        return True

    # ── Task 4: Simulation ─────────────────────────────────
    def run_simulation(self):
        step = 0
        while True:
            step += 1
            critical_remaining = any(
                v["status"]=="Critical" for v in self.hospital.values()
            )
            if not critical_remaining:
                print(f"\n✅ All critical patients treated!")
                break
            result = self.act()
            print(f"   Utility after step {step}: {self.utility()}")
            if not result: break
        print(f"\nFinal Utility: {self.utility()}")
        print(f"Treated: {self.critical_treated} | Moves: {self.moves}")

agent = UtilityBasedAgent(hospital, "WardB")
agent.run_simulation()

Q2 — A* Rescue Drone in Grid (18 pts)

Problem: 5×5 grid. S=start, G=goal. Terrain costs: .=1, W=3, F=5, #=blocked. Use A* with Manhattan heuristic.

Grid from exam: Row0:[S,.,.,W,.] Row1:[.,.#,.,#] Row2:[.,#,.,.,. ] Row3:[.,.,F,#,.] Row4:[.,.,.,.,G]
import heapq

# Grid: '.' safe(1), 'W' water(3), 'F' fire(5), '#' blocked, 'S' start, 'G' goal
raw_grid = [
    ['S', '.', '.', 'W', '.'],
    ['.', '.', '#', '.', '#'],  # W(row1,col3) from image
    ['.', '#', '.', '#', '.'],
    ['.', '.', 'F', '#', '.'],
    ['.', '.', '.', '.', 'G'],
]
COST = {'.':1, 'S':1, 'G':1, 'W':3, 'F':5}

rows, cols = len(raw_grid), len(raw_grid[0])
start = goal = None
for r in range(rows):
    for c in range(cols):
        if raw_grid[r][c] == 'S': start = (r,c)
        if raw_grid[r][c] == 'G': goal  = (r,c)

def h(pos): return abs(pos[0]-goal[0]) + abs(pos[1]-goal[1])

def astar_rescue():
    heap = [(h(start), 0, start, [start])]
    best = {}
    expanded = []

    while heap:
        f, g, pos, path = heapq.heappop(heap)
        if best.get(pos, float('inf')) <= g: continue
        best[pos] = g
        expanded.append(pos)
        print(f"Expand {pos} | g={g} h={h(pos)} f={f}")

        if pos == goal:
            print(f"\n✅ Path: {path}")
            print(f"Total cost: {g}")
            print(f"Expansion order: {expanded}")
            return path, g

        r, c = pos
        for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
            nr, nc = r+dr, c+dc
            if 0<=nrand 0<=ncand raw_grid[nr][nc] != '#':
                ng = g + COST[raw_grid[nr][nc]]
                nf = ng + h((nr,nc))
                heapq.heappush(heap, (nf, ng, (nr,nc), path+[(nr,nc)]))
    return None, float('inf')

Q3 — TSP with Genetic Algorithm (18 pts)

Problem: N cities, minimize total tour distance. Tasks: fitness, tournament selection, Order Crossover (OX), swap mutation, stop after max generations or target distance.

import random, math

# ── City coordinates (example from exam) ──────────────────
cities = [(2,3), (5,7), (1,9), (8,2), (4,5)]
N = len(cities)

# ── 1. Total distance ─────────────────────────────────────
def total_distance(route):
    dist = 0
    for i in range(N):
        c1, c2 = cities[route[i]], cities[route[(i+1)%N]]
        dist += math.sqrt((c1[0]-c2[0])**2 + (c1[1]-c2[1])**2)
    return dist

# ── 2. Tournament Selection ───────────────────────────────
def tournament_select(pop, fitnesses, k=3):
    t = random.sample(list(zip(pop, fitnesses)), k)
    return max(t, key=lambda x: x[1])[0]

# ── 3. Order Crossover (OX) ───────────────────────────────
def order_crossover(p1, p2):
    a, b = sorted(random.sample(range(N), 2))
    child = [None] * N
    child[a:b] = p1[a:b]
    remaining = [x for x in p2 if x not in child]
    idx = 0
    for i in range(N):
        if child[i] is None:
            child[i] = remaining[idx]; idx += 1
    return child

# ── 4. Swap Mutation ──────────────────────────────────────
def swap_mutate(route, rate=0.1):
    route = route[:]
    if random.random() < rate:
        a, b = random.sample(range(N), 2)
        route[a], route[b] = route[b], route[a]
    return route

# ── 5. Main GA ────────────────────────────────────────────
def ga_tsp(pop_size=50, max_gen=500, target_dist=24):
    pop = [random.sample(range(N), N) for _ in range(pop_size)]
    best_route = None; best_dist = float('inf')

    for gen in range(max_gen):
        dists = [total_distance(ind) for ind in pop]
        fits  = [1/d for d in dists]

        idx = dists.index(min(dists))
        if dists[idx] < best_dist:
            best_dist = dists[idx]
            best_route = pop[idx]
            print(f"Gen {gen}: Best Distance = {best_dist:.2f}")

        # Termination condition
        if best_dist <= target_dist:
            print(f"Target reached at generation {gen}!")
            break

        new_pop = [best_route]   # elitism
        while len(new_pop) < pop_size:
            p1 = tournament_select(pop, fits)
            p2 = tournament_select(pop, fits)
            child = order_crossover(p1, p2)
            child = swap_mutate(child)
            new_pop.append(child)
        pop = new_pop

    print(f"\nBest Route: {best_route}")
    print(f"Total Distance: {best_dist:.2f} units")
    return best_route, best_dist

ga_tsp()

🎯 EXAM TIPS:
1. Always import heapq for A*/UCS/GBFS and deque for BFS.
2. For grid problems: use (row, col) tuples as states.
