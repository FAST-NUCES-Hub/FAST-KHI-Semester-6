Question 1: Sudoku environment, task environment, and game theory

Marks: 2 + 2 + 2

a) Sudoku environment characteristics

PropertyClassificationReason
ObservabilityFully observableThe full grid, givens, and already-filled values are visible. There is no hidden state.
DeterminismDeterministicPlacing a digit has a predictable result. The puzzle rules do not involve chance.
Episodic vs sequentialSequentialEach placement affects later legal placements and the final solution.
Static vs dynamicStaticThe puzzle does not change while the solver is thinking. If a clock score is used it becomes semi-dynamic, but ordinary Sudoku is static.
Discrete vs continuousDiscreteCells, rows, columns, boxes, and digits 1 to 9 are finite discrete values.

b) PEAS task environment for Sudoku

  • Performance: fill all 81 cells correctly, obey row/column/box constraints, avoid contradictions, and solve efficiently.
  • Environment: the 9 by 9 grid, fixed clues, candidate digits, and Sudoku constraints.
  • Actuators: place a digit, erase a digit, mark candidates, choose next cell.
  • Sensors: read the current grid, fixed clues, empty cells, and constraint violations.

A Sudoku solver is naturally modeled as a problem-solving or CSP search agent.

c) Game-theoretic problems and non-zero-sum example

Game theory studies strategic interaction among decision makers, so game-theoretic problems are multi-agent in the usual AI sense. A non-zero-sum game is one where both agents can gain or both can lose.

Example: Prisoner's Dilemma. Mutual cooperation gives both players a better combined outcome than mutual defection, so the total payoff is not fixed at zero.

b) Will two K-means runs always produce the same result?

No. K-means can converge to different local optima because results depend on the initial centroids and tie-breaking. If the same seeds and same deterministic tie rule are used, the result is repeatable.

c) How clustering can improve linear regression

Cluster the data into more homogeneous groups first, then either train one regression model per cluster or add the cluster ID as an extra feature. This can capture piecewise linear behavior and reduce error when one global line is too simple.

d) What is learned in a regression model?

Learning a regression model means estimating its parameters: the intercept and the coefficient(s). In simple linear regression these are the y-intercept and slope. In multiple regression they are the intercept plus all feature weights.

a) Why calculate entropy and information gain?

Entropy measures how mixed or uncertain the class labels are. Information gain measures how much an attribute reduces that uncertainty. In ID3-style decision trees, the attribute with the highest information gain is chosen for the split.

Step-by-step Entropy and Information Gain calculations:

  1. Overall System Entropy H(S):
    Total students = 6. Class counts: Pass (T) = 4, Fail (F) = 2.
    H(S) = - (4/6) log2(4/6) - (2/6) log2(2/6) = - 0.6667 × (-0.585) - 0.3333 × (-1.585) = 0.390 + 0.528 = 0.9183
  2. Information Gain for GPA:
    We partition the set S into subsets for each GPA value:
    • GPA = L: 2 instances {F, T} → 1 Pass, 1 Fail. H(SL) = - (1/2)log2(1/2) - (1/2)log2(1/2) = 1.0
    • GPA = M: 2 instances {F, T} → 1 Pass, 1 Fail. H(SM) = - (1/2)log2(1/2) - (1/2)log2(1/2) = 1.0
    • GPA = H: 2 instances {T, T} → 2 Pass, 0 Fail. H(SH) = 0
    Weighted conditional entropy:
    H(S | GPA) = (2/6) × H(SL) + (2/6) × H(SM) + (2/6) × H(SH) = (2/6)(1.0) + (2/6)(1.0) + (2/6)(0) = 0.6667
    Information Gain:
    IG(GPA) = H(S) - H(S | GPA) = 0.9183 - 0.6667 = 0.2516
  3. Information Gain for Studied:
    We partition the set S into subsets for Studied:
    • Studied = T: 3 instances {T, T, T} → 3 Pass, 0 Fail. H(ST) = 0
    • Studied = F: 3 instances {F, F, T} → 1 Pass, 2 Fail. H(SF) = - (1/3)log2(1/3) - (2/3)log2(2/3) = - 0.333 × (-1.585) - 0.667 × (-0.585) = 0.9183
    Weighted conditional entropy:
    H(S | Studied) = (3/6) × H(ST) + (3/6) × H(SF) = 0.5(0) + 0.5(0.9183) = 0.4591
    Information Gain:
    IG(Studied) = H(S) - H(S | Studied) = 0.9183 - 0.4591 = 0.4591

Choose Studied as the root because it has higher information gain (IG = 0.4591) compared to GPA (IG = 0.2516).

Question 6: Bayesian networks and inference

Marks: 2 + 2 + 4

a) Bayesian network from factorization

Each conditional probability gives arrows from the variables after the bar into the variable before the bar.

B,C,E -> A D,G -> B E,F,H -> C G -> D G,H -> E I -> F H -> G I -> H I is a root

b) Robot localization with a noisy sensor

Use Bayes' rule. For every possible grid square L:

P(Location = L | Observation = o) = P(o | L) P(L) / sum_over_all_squares_j P(o | L_j) P(L_j)

The denominator normalizes the probabilities so all grid-square probabilities sum to 1.

c) Cancer Bayesian network calculations

The network variables and probability tables from the exam paper are defined as follows:

  • Pollution (P): P(P = H) = 0.1, P(P = L) = 0.9
  • Smoker (S): P(S = T) = 0.3, P(S = F) = 0.7
  • Cancer (C) Conditional Probability Table:
    • P(C = T | P = H, S = T) = 0.05
    • P(C = T | P = H, S = F) = 0.02
    • P(C = T | P = L, S = T) = 0.03
    • P(C = T | P = L, S = F) = 0.001

Step-by-step joint probability expansion:

  1. Calculate P(Cancer = T):
    We marginalize over Pollution (P) and Smoker (S):
    P(Cancer) = P(P=H, S=T, C=T) + P(P=H, S=F, C=T) + P(P=L, S=T, C=T) + P(P=L, S=F, C=T)
    P(Cancer) = P(C|H,T)P(H)P(T) + P(C|H,F)P(H)P(F) + P(C|L,T)P(L)P(T) + P(C|L,F)P(L)P(F)
    P(Cancer) = (0.05 × 0.1 × 0.3) + (0.02 × 0.1 × 0.7) + (0.03 × 0.9 × 0.3) + (0.001 × 0.9 × 0.7)
    P(Cancer) = 0.0015 + 0.0014 + 0.0081 + 0.00063 = 0.01163
  2. Calculate P(Pollution = L | Cancer = T):
    Using Bayes' rule:
    P(P = L | C) = P(C, P = L) / P(C)
    P(C, P = L) = P(P=L, S=T, C=T) + P(P=L, S=F, C=T) = (0.03 × 0.9 × 0.3) + (0.001 × 0.9 × 0.7) = 0.0081 + 0.00063 = 0.00873
    P(P = L | C) = 0.00873 / 0.01163 = 0.7506 (or 75.06%)
  3. Calculate P(Pollution = H | Cancer = T):
    By complements:
    P(P = H | C) = 1 - P(P = L | C) = 1 - 0.7506 = 0.2494 (or 24.94%)

Calculated probabilities: P(Cancer) = 0.01163. P(Pollution=L | Cancer) = 0.7506. P(Pollution=H | Cancer) = 0.2494. (Note: standard sensor conditional probabilities from the paper state P(XRay=pos | Cancer) = 0.90 and P(Dyspnoea=T | Cancer) = 0.65).

Question 1: Definitions, conditional independence, and PEAS

Marks: 10

A) Short definitions

  1. AI agent: an entity that perceives its environment through sensors and acts through actuators to maximize expected performance.
  2. Backpropagation: the algorithm that computes gradients of the loss with respect to neural-network weights by moving backward from output to input. We use it to update weights and reduce error.
  3. Supervised learning and reinforcement learning: both learn a mapping from inputs/states to outputs/actions. Supervised learning uses labeled examples; reinforcement learning learns from rewards received after actions.
  4. Activation function: transforms a neuron's weighted sum and introduces nonlinearity. Popular examples: ReLU, sigmoid, and tanh.
  5. MDP vs RL: an MDP is the mathematical model: states, actions, transition probabilities, and rewards. RL is the learning approach used to discover a good policy, often when the transition model is unknown.
  6. Conditional independence in A -> C <- B: C is a collider. If C is observed, A and B become dependent through explaining away. If C is unobserved, A and B are independent.
  7. Gradient descent: repeatedly update weights in the negative-gradient direction: w := w - alpha * dL/dw.
  8. Impurity vs abnormality: impurity is class mixing inside a dataset or tree node, measured by entropy or Gini. Abnormality means unusual or outlier behavior compared with the expected data pattern.

Question 4: Linear activations, XOR, and feedforward propagation

Marks: 2 + 4 + 4

A) Network with linear activation

If each unit output is c times its weighted sum, a hidden layer does not add nonlinearity. The whole network collapses to one linear transformation.

h_j = c * (sum_i w1_ji x_i + b1_j) y_k = c * (sum_j w2_kj h_j + b2_k) = c * (sum_j w2_kj * c * (sum_i w1_ji x_i + b1_j) + b2_k)

After expanding, y is still a weighted sum of input x plus a constant. So multiple linear layers are equivalent to a single linear layer.

B) Neural architecture for XOR

XOR is not linearly separable, so use at least one hidden layer with nonlinear/threshold neurons.

Hidden h1 = step(x1 + x2 - 0.5) // OR Hidden h2 = step(-x1 - x2 + 1.5) // NAND Output y = step(h1 + h2 - 1.5) // AND(OR, NAND) = XOR

C) Feedforward output for self-driving car network

The PDF weight table labels the x2-to-hidden layer weights as b21, b22, b23. We treat these as weights w21, w22, and w23 respectively. Biases for hidden neurons are b3 = -0.5, b4 = 0.3, b5 = 0.6, and output neuron bias is b6 = 0.25. (Note: the extra value b7 = 0.1 is not used in this architecture; if it is used in place of b6, the output becomes O = 0.5758).

b) Calculate P(OS = PASS | ITC = PASS)

The Bayesian network structure is: OOP → DS, ITC → DS, and DS → OS. The Conditional Probability Tables (CPTs) are defined as:

  • OOP: P(OOP = PASS) = 0.4, P(OOP = FAIL) = 0.6
  • ITC: P(ITC = FAIL) = 0.4 → P(ITC = PASS) = 0.6
  • DS CPT (P(DS = PASS | OOP, ITC)):
    • P(DS = PASS | OOP = PASS, ITC = PASS) = 0.2
    • P(DS = PASS | OOP = PASS, ITC = FAIL) = 0.8
    • P(DS = PASS | OOP = FAIL, ITC = PASS) = 0.3
    • P(DS = PASS | OOP = FAIL, ITC = FAIL) = 0.9
  • OS CPT (P(OS = FAIL | DS)):
    • P(OS = FAIL | DS = PASS) = 0.7 → P(OS = PASS | DS = PASS) = 0.3
    • P(OS = FAIL | DS = FAIL) = 0.2 → P(OS = PASS | DS = FAIL) = 0.8

Step-by-step Conditional Probability working:

  1. Find P(DS = PASS | ITC = PASS):
    Since OOP is independent of ITC, we use the law of total probability to marginalize over OOP:
    P(DS=PASS | ITC=PASS) = P(DS=PASS | OOP=PASS, ITC=PASS)P(OOP=PASS) + P(DS=PASS | OOP=FAIL, ITC=PASS)P(OOP=FAIL)
    P(DS=PASS | ITC=PASS) = (0.2 × 0.4) + (0.3 × 0.6) = 0.08 + 0.18 = 0.26
    This means P(DS = FAIL | ITC = PASS) = 1 - 0.26 = 0.74.
  2. Find P(OS = PASS | ITC = PASS):
    Since OS is conditionally independent of OOP and ITC given DS (Markov property of networks), we marginalize over DS:
    P(OS=PASS | ITC=PASS) = P(OS=PASS | DS=PASS)P(DS=PASS | ITC=PASS) + P(OS=PASS | DS=FAIL)P(DS=FAIL | ITC=PASS)
    P(OS=PASS | ITC=PASS) = (0.3 × 0.26) + (0.8 × 0.74)
    P(OS=PASS | ITC=PASS) = 0.078 + 0.592 = 0.67

P(OS = PASS | ITC = PASS) = 0.67 (or 67%).

Question 1: Brief conceptual answers

Marks: 10
  1. Rational agent characteristics: perceives the environment, selects actions that maximize expected performance, uses available knowledge, handles uncertainty, and can improve from experience.
  2. Why CSPs use factored state representation: a CSP is compactly represented by variables, domains, and constraints. This avoids enumerating every complete state and lets algorithms exploit local constraint structure.
  3. Drone environment episodic or sequential: sequential. Each delivery action affects later position, battery, route options, timing, and safety.
  4. Local beam search vs hill climbing: hill climbing keeps one current state. Local beam search keeps k states, expands all their successors, and keeps the best k for the next step.
  5. DFS vs BFS complexity: BFS has time and space O(b^(d+1)); it is complete and optimal for equal step costs. DFS has time O(b^m), space O(bm), may be incomplete in infinite depth, and is not optimal.
  6. Rook Manhattan heuristic admissible? False. A rook can move across a whole row/column in one move, so Manhattan distance can overestimate. Example: distance 7 squares in same row, true cost 1.
  7. Minimax optimality: minimax guarantees the best worst-case outcome when the opponent is optimal. Against a non-optimal opponent, minimax remains safe but may miss strategies that exploit mistakes.
  8. Two hill-climbing limitations: it can get stuck in local maxima and plateaus/ridges; it is also sensitive to the starting state and not guaranteed optimal.
  9. CSP search tree size: with commutativity/fixed variable order, leaves are d^n. Without commutativity, the same assignments can appear in n! orders, giving n! d^n leaves.
  10. Iterative deepening in adversarial search: yes. Depth-limited minimax/alpha-beta can be run at depths 1, 2, 3, ... until time runs out, returning the best move found so far.
